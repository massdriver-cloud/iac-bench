# Request: a GKE Standard module for production clusters

Our platform team runs the Kubernetes clusters our product teams deploy to, and we're replacing a handful of hand-built clusters with one standard module that every new cluster comes from. Build the reusable OpenTofu module the platform team will use to create and operate these clusters, all GKE Standard, from now on. Each cluster is shared by several product teams and runs production workloads, so the clusters need to be resilient and secure. Those workloads use other Google Cloud services, such as Pub/Sub, Cloud Storage and Cloud SQL. The network team owns one VPC per environment (`apps-staging` and `apps-prod`) and has already created a subnet for GKE in each of our US regions, named `<vpc>-gke-<region>`, with secondary ranges named `pods` and `services`. The clusters go in the same Google Cloud project as those VPCs, and the Google provider is already configured for that project. The workloads handle customer data, and the security team audits access to the clusters. The platform team is small: its engineers know Kubernetes well but aren't GKE specialists, they'll fill in what's specific to each cluster, and they'll trust the module for the rest. You own every design decision the module makes.
