# Request: a standard storage account module for our app teams

Our application teams create Azure storage accounts by hand for the files their applications store and work with, such as user uploads, images and videos, and generated reports and exports, and every account comes out a little different. Build the reusable OpenTofu module that will become the standard way an app team gets storage for its application. The applications run on AKS and App Service, and every application already has its own identity in our Entra ID tenant. Some of those files contain customer PII. Each application already has its own resource group in each environment, such as `orders-staging` and `orders-prod`, and an application's storage belongs in its resource group; the azurerm provider is already configured for the subscription that holds them. The people who will use the module are application developers who don't know Azure Storage well and shouldn't have to: they'll copy an example, fill in a couple of obvious inputs, and trust the module's judgment for everything else. You own every design decision the module makes.
